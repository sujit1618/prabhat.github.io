NATURE 2027 DESIGN | PRABHAT CALENDARS

Each monthly folder contains index.html in English, index-mr.html in Marathi and an assets folder. There are 12 calendar months plus an additional Ashy Prinia option for June. The top-right language button switches between English and मराठी.

Both bird names appear on each version. English pages show the English name first. Marathi pages show the Marathi name first. Marathi uses embedded Palanquin Regular. English uses Philosopher. January’s Marathi name is तुरेवाला भारीट.

All images, fonts and bundled recordings are embedded in each HTML file for offline use. No server or installation is needed. The eBird links, original-photo links and online audio catalogues need internet. Each page has a main bird photograph and two supporting photographs. No photo from the calendar PDFs is used.

Each assets folder includes editable media files, styles, font licences and media credits. English and Marathi versions share those assets. The visible layout follows the approved template with brown text, buttons and uniform thin divider lines.

To open a page, unzip the archive and open a month’s index.html or index-mr.html. Keep the two HTML files together for the language switch to work.
